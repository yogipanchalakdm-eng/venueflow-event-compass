# BAPS Houston Hub

okay so before we begin, i have a couple of questions and want to know if you are capable of making this. I want to make a website for a venue where multiple events are held. The website will have a public side which is the  request form for different departments (ie. facilities team, IT network team, AV team, Photo/Video Team, kitchen team, ect) and also the internal password protected side which is where the management team can plan and manage the events. Each department lead would need an account and their account should only be able to see their departments information and the dashboard tab should show the event as a "card" with basic info such as only names of the departments that are required and when clicked on opens up all the submitted information for that event (kind of like a logistics document for the whole event with the info for all the events. So for this, are you able to send email reminders and notifications to a person from each department that gets requested in the form (ie. if the event only requests AV then only the av people get an email)? Also since this venue has multiple sections, are you able to make an interactive 2d map if i provide you the map image where the requesters are able to select which rooms they want? Lastly, if we have a @connector:telegram:"Telegram" group, are you able to connect to that @connector:telegram:"Telegram" group and send notification/reminders for any new or upcoming requests and tag those respective department leads? Also would you able to optimize this website for the phone and web?
